Unity Projects

My first interaction with coding was through Unity, which makes these projects especially meaningful to me. I usually build them as a hobby whenever I dream up a game or a new idea pops into my head, I try to bring it to life here and sometimes in GameJams XD.

This is my first Game Jam project, created during a 2-day DOGE Game Jam. Everything you see in this clip is my contribution to the game. The concept is simple: you must transport an ill patient to the hospital within a limited time. (The timer isn't visible in this clip, but it works in the actual game!)
I also started an Avatar(the last airbender) inspired online fighting game, beginning with earthbending. The mechanics worked well, but I paused it due to my short free times.But Eventually whenever i find a good free time to spend, I plan to expand it to all four elements.
The 2D parkour game you're seeing now is the first 2D platformer I ever made. I had so many ideas in my mind but I wasn't sure if I could pull them off, so I started simple; basic movement, mechanics and a small parkour map to build from.
This was another project I started with an idea in mind, but before jumping into the main concept, I wanted to get the movement system right. I pieced it together by mixing some borrowed( ;D ) code, my own coding skills, and tips from diffrent youtube tutorials.
